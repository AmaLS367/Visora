# 🔐 Security Policy

> Security reports are welcome. Please report them privately so users have time to update safely.

---

## 🛡️ Supported versions

| Version | Security support |
| --- | --- |
| Latest `0.1.x` release | ✅ Supported |
| Earlier releases | ⚠️ Upgrade first |

---

## 📬 Reporting a vulnerability

**Do not report vulnerabilities in public GitHub issues.** Use [GitHub's private vulnerability reporting form](https://github.com/AmaLS367/Visora/security/advisories/new) and include:

- a clear description of the impact;
- affected Visora and Unity bridge versions;
- minimal reproduction steps or a proof of concept;
- any suggested remediation.

> 🧩 Do not include credentials, API tokens, or proprietary Unity project data.

Reports are acknowledged as soon as practical. Fixes are coordinated privately before public disclosure.
