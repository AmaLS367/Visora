## 🧾 When Opening an Issue

To help us diagnose and resolve issues swiftly, please provide:
1. **Versions**: Visora server version, Unity Editor version (e.g. `6000.0.35f1`), and bridge mode (`native` or `legacy`).
2. **Context**: The specific tool call, input arguments, and expected vs actual result.
3. **Logs**: Relevant console output from Python (`--log-level DEBUG`) and the Unity Editor console.

> [!CAUTION]
> **Data Privacy**: Always sanitize logs before posting. Never share credentials, API keys, private repository URLs, or proprietary 3D assets.
