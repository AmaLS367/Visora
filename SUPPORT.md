# 💬 Support

> Start with the path that best matches what you need — it helps us keep issues focused and actionable.

---

## 🧭 Find the right place

| You need help with… | Best next step |
| --- | --- |
| Installation, Unity bridge, or MCP client setup | Read the [setup guide](docs/SETUP_GUIDE.md). |
| Tool behavior and diagnostic recipes | Read the [agent workflow guide](docs/AGENT_WORKFLOWS.md). |
| A reproducible defect | Open a GitHub bug report. |
| Using Visora for a specific workflow | Use the Usage question form. |
| A security concern | Follow [SECURITY.md](SECURITY.md) privately. |

---

## 🧾 When opening an issue

Include the Visora, Unity, and bridge versions, plus the workflow you are trying to complete. Please remove credentials, API tokens, private Unity assets, and proprietary project data before posting.
